# COVID-19 Global Analysis

An end-to-end data analytics project exploring global COVID-19 confirmed case trends using Python, Pandas, time-series aggregation, and Power BI.

The project transforms raw cumulative COVID-19 data into analysis-ready daily, monthly, and yearly datasets before presenting global trends through an interactive Power BI dashboard.

## Project Overview

COVID-19 data is commonly distributed as cumulative time-series data, which is useful for tracking total confirmed cases but less convenient for analyzing how case activity changes over time.

This project transforms the original dataset into multiple analytical views to answer questions such as:

- How did global COVID-19 cases change over time?
- Which years recorded the largest number of new confirmed cases?
- Which months experienced the highest global case activity?
- How can cumulative time-series data be transformed into daily case counts?
- How can the processed data be prepared for dashboard reporting?

The analytical workflow follows:

**Raw Data → Data Transformation → Daily Cases → Monthly & Yearly Aggregation → Power BI Dashboard → Insights**

## Data Preparation

The original dataset contains COVID-19 confirmed case data organized by country or region, with dates stored across multiple columns.

### Reshaping the Dataset

The dataset was transformed from wide format into long format using Pandas `melt()`:

```python
df_melted = df.melt(
    id_vars=['Country/Region'],
    var_name='Date',
    value_name='Cases'
)

df_melted['Date'] = pd.to_datetime(df_melted['Date'])
```

This transformation creates a structure that is easier to analyze, filter, aggregate, and visualize.

---

## Global Time-Series Transformation

The cumulative confirmed cases from all available geographic records were aggregated into a global time series:

```python
df_global = df.iloc[:, 4:].sum().reset_index(name='Cases')
df_global = df_global.rename(columns={'index': 'Date'})
df_global['Date'] = pd.to_datetime(df_global['Date'])
```

Because the source data represents cumulative confirmed cases, daily new cases were derived using the difference between consecutive dates:

```python
df_daily = (
    df.iloc[:, 4:]
      .sum()
      .diff()
      .reset_index(name='Cases')
)

df_daily = df_daily.rename(columns={'index': 'Date'})
df_daily['Date'] = pd.to_datetime(df_daily['Date'])
```

This creates a daily series representing changes in cumulative confirmed cases.

---

## Time-Based Aggregation

The daily data was further aggregated into monthly and yearly views.

### Monthly

```python
df_monthly = (
    df_daily
    .resample('M', on='Date')
    .sum()
    .reset_index()
)
```

### Yearly

```python
df_yearly = (
    df_daily
    .resample('Y', on='Date')
    .sum()
    .reset_index()
)
```

These transformations make it easier to compare large-scale changes across different periods.

# Analysis

## Global Cases by Year

The processed yearly dataset shows the following totals:

| Year | New Confirmed Cases |
|---|---:|
| 2020 | 83,778,065 |
| 2021 | 204,949,669 |
| 2022 | 371,735,501 |
| 2023* | 16,106,357 |

\*2023 data in this project only covers the available period through March 2023.

### Key Observation

**2022 recorded the highest annual number of new confirmed cases in the processed dataset, with approximately 371.7 million cases.**

The number was substantially higher than both 2020 and 2021.

## Monthly Case Trends

Monthly aggregation reveals several major periods of increased global case activity.

**90,483,564 new confirmed cases**

This was followed by:

| Period | New Confirmed Cases |
|---|---:|
| January 2022 | 90,483,564 |
| February 2022 | 58,251,972 |
| March 2022 | 51,347,034 |

The beginning of 2022 therefore represents the strongest concentration of global confirmed cases within the analyzed monthly data.

## Daily Analysis

Daily case counts were generated by calculating the difference between cumulative global totals.

The available daily series begins on **January 22, 2020** and is used as the foundation for the monthly and yearly aggregations.

This allows the project to move beyond cumulative totals and analyze how case activity changed between individual reporting periods.

# Key Findings

### 1. Global case activity increased significantly after 2020

The processed data shows approximately **83.8 million** new confirmed cases during 2020, followed by approximately **204.9 million** during 2021.

This represents a substantial increase in global reported case activity.

### 2. 2022 recorded the highest annual total

Approximately **371.7 million** new confirmed cases were recorded in the processed 2022 data, making it the highest annual total within the analyzed period.

### 3. Early 2022 represented the largest monthly surge

January 2022 recorded approximately **90.5 million** new confirmed cases, the highest monthly value in the processed dataset.

February and March 2022 also remained substantially elevated.

### 4. Time aggregation makes large-scale patterns easier to identify

Daily case data contains considerable variation.

Aggregating the data into monthly and yearly periods makes major global trends easier to compare and communicate through reporting dashboards.

# Limitations

Several limitations should be considered when interpreting the results:

- The project analyzes reported confirmed case data rather than the true number of infections.
- Reporting practices may differ between countries and periods.
- Historical corrections to cumulative case data can affect daily values calculated using `diff()`.
- The available 2023 data is incomplete and should not be directly compared with full calendar years.
- The analysis focuses primarily on global time trends rather than epidemiological modeling.
- The dataset does not provide enough information in this project to infer causes behind changes in case counts.

Therefore, the findings should be interpreted as **descriptive analysis of reported COVID-19 case trends**, not epidemiological conclusions.
